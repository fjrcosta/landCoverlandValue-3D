Methodological note

One scene, two model outputs

The default integrated layer assigns each 109.45 m TabPFN grid cell the nearest DINOv2–LoRA land-cover classification. Prism height encodes the predicted median unit land value, while prism color encodes land-cover class. The optional value tint adds a second continuous color cue.

Urban land coverDINOv2 ViT-L/14 with LoRA; 10 mutually exclusive classes and classification confidence.
Urban land valueTabPFN v2, configuration 60; the median unit-value estimate is used directly in R$/m² for a 450 m² reference parcel.
Spatial integrationNearest-neighbour association in a projected metric CRS, performed offline by the preprocessing script.
RenderingMapLibre GL JS with selectable OpenFreeMap or Esri World Imagery basemaps and deck.gl GPU grid-cell extrusion. Static hosting; no application server is required.
